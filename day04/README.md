---

## 🔧 Operators Learned

### Arithmetic Operators
* `+` Addition, `-` Subtraction, `*` Multiplication, `/` Division, `//` Floor Division, `%` Modulus, `**` Exponent

### Comparison Operators
* `==`, `!=`, `>`, `<`, `>=`, `<=`

### Assignment Operators
* `=`, `+=`, `-=`, `*=`, `/=`, `%=`

### Logical Operators
* `and`, `or`, `not`

### Membership Operators
* `in`, `not in`

### Identity Operators
* `is`, `is not`
